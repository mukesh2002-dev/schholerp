# School ERP — Master Prompt

Build a complete production-style School Management Platform / ERP using Next.js 15+, TypeScript, App Router, Tailwind CSS, shadcn/ui, Lucide icons, Recharts, React Hook Form, Zod and TanStack Table.

## Core Requirements
- Responsive desktop/tablet/mobile UI
- Light/dark mode
- Reusable components
- Dummy but relational data
- Mock service/data layer
- Forms with validation
- Tables with search/filter/sort/pagination
- Detail pages, drawers/modals, confirmations and toasts
- Loading, empty and error states
- Accessible UI
- Demo authentication and role-aware navigation

## Main Modules
Dashboard, Branches, Admissions, Students, Classes, Teachers, HR/Staff, Workers, Fees, Attendance, Biometric placeholder, Notifications, Parents, Transport, Timetable, Homework, Exams/Results, Communication, Events, Inventory, Expenses, Payroll, Documents, Reports, Settings, Global Search, Audit Logs.

## Engineering Rules
Keep types, mock data, services and UI components separated. Avoid hardcoded repeated data. Keep routes organized by module. All actions must work in demo mode. Do not claim real payment, biometric, SMS, email, CI/CD or deployment integrations unless actually implemented.

## Workflow
Implement the project phase-by-phase using the files in this folder. After each phase, run checks, fix errors, and stop until the next phase is explicitly started.
