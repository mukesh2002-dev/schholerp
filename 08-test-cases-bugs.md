# Phase 08 — QA, Test Cases & Bug Management

## Test Case Management
Build:
- QA dashboard
- test cases
- test suites
- test plans
- test runs
- test execution
- test history
- test reports

Fields:
ID, title, module, preconditions, steps, expected result, actual result, status, priority, severity, assignee, environment.

Statuses:
Draft, Ready, Passed, Failed, Blocked, Skipped.

## Bug / Issue Management
Build:
- bug list
- bug detail
- create/edit bug
- severity
- priority
- status
- assignee
- environment
- reproduction steps
- expected vs actual result
- attachments placeholder
- comments/activity
- linked test case

Statuses:
Open, In Progress, Fixed, Retest, Reopened, Closed, Rejected.

## QA Metrics

- pass rate
- fail rate
- blocked tests
- open bugs
- critical bugs
- bugs by module
- execution trend
