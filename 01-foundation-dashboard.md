# Phase 01 — Foundation, Dashboard & Branches

Read `00-master-prompt.md` first.

## Goal
Create the application foundation and a polished dashboard.

## Build
1. Next.js App Router structure.
2. TypeScript types and shared utilities.
3. Tailwind + shadcn/ui design system.
4. Responsive sidebar/topbar/breadcrumbs.
5. Theme switcher.
6. Global search UI.
7. Demo login/auth UI and role selector.
8. Reusable cards, buttons, dialogs, forms, tables, badges, empty/loading/error states.
9. Mock data/service architecture.
10. Branch Management:
   - branch list
   - branch detail
   - add/edit branch
   - status
   - principal/contact information
   - branch statistics
11. Dashboard:
   - students
   - teachers
   - staff/workers
   - attendance
   - fees
   - admissions
   - transport
   - notices
   - charts
   - recent activities
   - quick actions
12. Add realistic relational dummy data for 6 branches.

## Important
Do not build later modules yet.

## Verification
Run TypeScript/lint/build checks. Fix all errors. Check responsive and dark mode. Verify every visible dashboard action works.
